# «Где купить в банке» — блок для Tilda

Рабочая версия страницы https://robimgood.beer/mestaprodazh (этап 1, вариант 2 из `brief/`).

| Файл | Что это |
|---|---|

| `dist/preview-v2.html` | Предпросмотр версии 2 |

| `dist/preview.html` | Тот же блок под шапкой, похожей на шапку сайта, для проверки в браузере |

Все настройки находятся в начале скрипта блока, в объекте `RG_CONFIG`:

```js
sheetCsvUrl: '',     // ссылка на Google-таблицу в CSV
yandexMapsKey: '',   // ключ Яндекс Карт
untappdCsvUrl: '',   // лист «untappd» той же таблицы в CSV
```

Пока поля пустые, страница берёт встроенный список точек, а карта работает на OpenStreetMap.

## 1. Как вставить на Tilda

1. Откройте страницу «Места продаж ж/б» в редакторе Tilda.
2. Удалите старые блоки: обложку с банками, заголовок «Места продаж», бегущую строку, «Главный партнер», «Партнеры» и «Связаться с нами». Шапку-меню **не трогайте**.
3. Сразу под меню добавьте блок: **«+» → «Другое» → T123 «HTML-код»**.
4. Откройте у блока «Контент», вставьте **всё** содержимое файла `dist/tilda-block.html` и сохраните.
5. Удалите нижнюю полосу сайта с телефоном (блок T396) и блок «Связаться с нами»: подвал теперь входит в новый блок (тёмный блок «Связаться с нами» и полоса с фирменной графикой), со всеми ссылками рабочими. В старой полосе ссылка звонка вела на неверный номер `+3752968580901`, а почта на `opt@tochca.by`.
6. **Настройки страницы → SEO:**
   - Заголовок: `Где купить Robim Good в банке — Минск и вся Беларусь`
   - Описание: `Магазины и бары, где продают баночное пиво Robim Good: Zero IPA, Zero Lager, FACTORY I.P.A Vista и TOMATO BBQ. Найдите ближайшую точку.`
7. Нажмите «Опубликовать» и проверьте страницу с телефона.

## 2. Google-таблица для менеджера

1. Создайте Google-таблицу. **Файл → Импорт → Загрузка** → выберите `data/points.csv` → «Заменить таблицу».
2. **Файл → Поделиться → Опубликовать в интернете** → выберите этот лист и формат **«Значения, разделённые запятыми (.csv)»** → «Опубликовать».
3. Скопируйте ссылку и вставьте её в `sheetCsvUrl` (в Tilda: «Контент» блока, строка `sheetCsvUrl: ''`).

После этого менеджер меняет строку, и через несколько минут изменение появляется на сайте (Google обновляет опубликованный файл примерно раз в 5 минут). Если таблица недоступна, страница показывает встроенный список и сообщает, что он сохранённый.

**Правила для таблицы:**
- `type`: «Магазин», «Бар» или «Магазин-бар».
- `phone`: номер в любом виде. Если пусто, кнопка «Позвонить» не показывается.
- `lat`, `lng`: координаты. Найти их можно в Яндекс Картах: правый клик по зданию, координаты появятся в карточке.
- `tochka`: «да» для сети «Точка».
- `sorts`: сорта через запятую, например `Zero IPA, Zero Lager, FACTORY IPA, TOMATO BBQ`.
  **Пока колонка пустая у всех точек, фильтр по сортам скрыт.** Он появится сам, как только сорта будут заполнены хотя бы у одной точки.

**Что проверить вручную.** Координаты подобраны автоматически по адресам. У четырёх точек они пока с точностью до улицы, без номера дома: Могилёв, ул. Пысина, 9; Брест, ул. Жукова, 2; Гомель, ул. Студенческая, 4 и ул. Советская, 97/3. Две точки стоят на рынках без точного адреса: Гродно, мини-рынок «Фолюш»; Мозырь, мини-рынок «Натали». Поправьте их `lat`/`lng` в таблице.

## 3. Ключ Яндекс Карт

1. Откройте https://developer.tech.yandex.ru и войдите в Яндекс ID (в аккаунт компании).
2. Нажмите **«Подключить API»** → выберите **«JavaScript API и HTTP Геокодер»**.
3. Заполните форму (сайт: `robimgood.beer`) и подтвердите. Сначала прочитайте условия тарифа: бесплатный тариф для коммерческого сайта может не подойти, Яндекс подскажет при оформлении.
4. В карточке ключа откройте **«Ограничение по HTTP Referer»** и добавьте `robimgood.beer` и `*.robimgood.beer`. Так ключ не смогут использовать на чужих сайтах.
5. Подождите до 15 минут, пока ключ активируется.
6. Вставьте ключ в `yandexMapsKey: ''` или пришлите его, и я вставлю и пересоберу блок.

Ключ всё равно виден в коде страницы. Это нормально, его защищает ограничение по Referer из шага 4.

## 4. Оценки в Untappd

Блок «Оценки в Untappd» показывает общий рейтинг пивоварни и рейтинг четырёх баночных сортов, а кнопка «Оценить» открывает страницу сорта в Untappd (на телефоне сразу в приложении).

Сорта сопоставлены по этикеткам, крепость и IBU совпадают:

| На банке | Карточка в Untappd |
|---|---|
| FACTORY I.P.A Vista | [Factory IPA Vista](https://untappd.com/b/robim-good-brewery-factory-ipa-vista/6753498) |
| FACTORY TOMATO BBQ (5,1%) | [BBQ Tomato Beer](https://untappd.com/b/robim-good-brewery-bbq-tomato-beer/6798506). Старая карточка «Factory Tomato BBQ» на 6% не используется |
| Zero IPA | [Robim Good ZERO IPA](https://untappd.com/b/robim-good-brewery-robim-good-zero-ipa/6772342) |
| Zero Lager | [Robim Good ZERO](https://untappd.com/b/robim-good-brewery-robim-good-zero/6772340) |

**Как рейтинг обновляется.** Официальный API Untappd требует секретный ключ, который нельзя держать в коде страницы, а браузер не даёт читать Untappd с чужого сайта. Поэтому рейтинги раз в день забирает скрипт в Google-таблице:

1. Откройте Google-таблицу с точками → **Расширения → Apps Script**.
2. Вставьте содержимое `integrations/untappd.gs` вместо кода в редакторе и сохраните.
3. Вверху выберите функцию **install** → «Выполнить» → разрешите доступ. Появится лист **untappd** с рейтингами. Дальше он обновляется каждый день в 6:00.
4. **Файл → Поделиться → Опубликовать в интернете** → выберите лист **untappd**, формат CSV → «Опубликовать». Ссылку вставьте в `untappdCsvUrl` в блоке.

На листе можно менять название сорта (`beer`), ссылку на карточку (`url`) и добавить отзыв покупателя (`quote`, `quote_author`). Отзыв ставьте только с разрешения автора, тогда он появится под рейтингами. Если Untappd не ответит, на листе останутся последние известные значения. Если лист недоступен, страница покажет встроенную копию рейтингов (`data/untappd.csv`, обновляется командой `python3 where-to-buy/tools/untappd_snapshot.py`).

Скрипт читает публичные страницы Untappd раз в день, по одной странице на сорт. Untappd может это ограничить. Тогда рейтинг на странице просто перестанет обновляться, а вёрстка не сломается.
